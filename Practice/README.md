# Practice

A scratch-pad of **Swing/AWT practice programs** built while learning UI programming.

## Component & widget demos

| File | Topic |
| --- | --- |
| `MyApp.java` | A simple Swing app with a frame |
| `SwingWidgetsExample.java` | Tour of common Swing widgets |
| `AddTwoNumbers.java` | Calculator-style frame with two inputs |
| `AllControlsDemo.java` | Various controls in one window |
| `Try.java` | Small experimental program |

## Layouts

| File | Topic |
| --- | --- |
| `LayoutManager.java` | Layout manager experiments |
| `GridBagExample.java` | `GridBagLayout` demo |
| `GroupLayoutExample.java` | `GroupLayout` demo |

## Menus, dialogs, choosers

| File | Topic |
| --- | --- |
| `MenuDemo.java` | Menu bar example (uses `tulsa1.png` icon) |
| `MenuPractice.java` | Music-player style menu demo (uses `tulsa1.png` icon) |
| `OptionDialogExample.java` | `JOptionPane` message/confirm/input dialogs |
| `PopupMenuExample.java` | Right-click popup menus |
| `SimplePopup.java` | Minimal popup example |
| `ColorChooserExample.java` | `JColorChooser` |
| `FileChooserExample.java` | `JFileChooser` open/save |
| `InternalFrameExample.java` | Internal frames in a desktop pane |

## Event handling

| File | Topic |
| --- | --- |
| `EventHandlingExample.java` | Using action listeners |

## Networking (subfolder)

| Folder | Topic |
| --- | --- |
| `socket/` | A TCP "greatest number" client/server pair, see [socket/README.md](socket/README.md) |

## Requirements
- JDK 8+

## Run
```bash
javac MenuDemo.java
java MenuDemo
```
Each file has its own `main` method, replace the file name to run another demo. A window will open.
