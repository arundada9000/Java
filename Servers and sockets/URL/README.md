# URL

Using **java.net.URL** and **HttpURLConnection** to talk to web servers.

| File | Topic |
| --- | --- |
| `URLExample.java` | Basic `URL` parsing and reading stream data |
| `HttpURLConnectionExample.java` | HTTP GET with `HttpURLConnection` |
| `URLConnectionCustomHeaders.java` | Sending a request with custom headers |
| `URLConnectionPOSTExample.java` | HTTP POST with a request body |

## Requirements
- JDK 8+
- Internet connection

## Run
```bash
javac URLExample.java
java URLExample
```
Replace the file name to run another example. No server setup needed.
