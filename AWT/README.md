# AWT

Examples of **AWT (Abstract Window Toolkit)** UI components, frames, dialogs, menus and a student-registration form.

| File | Purpose |
| --- | --- |
| `FirstFrame.java` | Create and show the first AWT `Frame` |
| `DialogBox.java` | Modal / modeless `Dialog` example |
| `FileDialogDemo.java` | Open and save file dialogs |
| `MenuDemo.java` | Menu bar with menus and menu items |
| `StudentRegistration.java` | A simple student-registration form using `Frame` + components |

## Requirements
- JDK 8+

## Run
```bash
javac StudentRegistration.java
java StudentRegistration
```
Each file has its own `main` method, replace the file name to run another demo. A window will open.
