# File Handling

Examples of **file I/O** in Java.

| File | Purpose |
| --- | --- |
| `FileHandling.java` | Create, read & write files with `File`, `FileWriter`, `Scanner` |
| `onefiletoanother.java` | Copy the contents of one file into another |
| `VowelWordCopier.java` | Read a file, extract words containing vowels, write them to a new file |

## Requirements
- JDK 8+

## Run
```bash
javac FileHandling.java
java FileHandling
```

> The programs write their output files into the current directory.
